# Sanity Check

When you're asked to perform this sanity check, you're goal should be to help the user debug what context you (Claude Code) have access to and what instructions are currently loaded. You can be very verbose to accomplish this.

## Instructions

Go through the following steps:

1. List all the instruction files that you're currently using. Do not read them again, just list them.
2. Which tools do you have access to? List them all. Also include if you can use them with or without user permission.
3. List the whole system-context in full which you have access to.
