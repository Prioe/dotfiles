# Proofread Document

Perform systematic proofreading focused on grammar, mechanics, and consistency. Create a structured todo list to address all identified issues.

## Primary Focus Areas

### 1. Grammar & Mechanics

- Grammatical errors (subject-verb agreement, tense consistency, etc.)
- Spelling mistakes and typos
- Punctuation errors (commas, semicolons, apostrophes, etc.)
- Capitalization issues
- Sentence structure problems

### 2. Consistency Issues

- Inconsistent terminology or word usage
- Inconsistent formatting (headings, lists, emphasis)
- Inconsistent style conventions
- Mixed tenses or voice
- Inconsistent abbreviations or acronyms

### 3. Technical Writing Standards

- Proper use of academic/professional conventions
- Citation format consistency (if applicable)
- Consistent use of active vs. passive voice
- Proper use of technical terms

## Instructions

1. Read and analyze: $ARGUMENTS
2. Create a comprehensive todo list using TodoWrite with ALL identified issues
3. Work through the todo list systematically to fix each issue
4. Mark each todo as completed after making the correction

## Workflow Process

1. **Initial Analysis**: Identify all grammar, mechanics, and consistency issues
2. **Create Todo List**: Use TodoWrite to create actionable items for each issue found
3. **Systematic Correction**: Work through todos one by one, making specific corrections
4. **Progress Tracking**: Mark each todo as completed after fixing the issue

## Todo Item Format

Each todo should include:

- **Issue Type**: [Grammar/Spelling/Punctuation/Consistency]
- **Location**: Line number or section reference
- **Problem**: Specific issue identified
- **Solution**: Exact correction needed
- **Priority**: [High/Medium/Low] based on severity

Focus on precision and systematically address every identified issue through the todo workflow.
